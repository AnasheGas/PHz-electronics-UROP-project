# Nanoantenna LTspice Models

This repository contains the LTspice schematics for various models of
nanoantennas. The models simulate the electrical behavior driven by the
nonlinear charge-mediated interaction of an antenna or a network of
antennas when illuminated by ultrafast optical pulses.

The primary objective is to study the interaction dynamics between
coupled nanoantennas and evaluate their response characteristics for
potential integration into larger on-chip circuit components.

This README outlines the file structure, simulation procedures, and
processing workflow.

## SPICE File Structure

### `.asc` Files

Hold SPICE's visual representation of circuit components and their
graphical design, created within LTspice. These files define the
schematic layout, including how components are placed and connected
visually. These are the files that users edit to modify the simulation.

### `.log` Files

Record output results and data from the most recent SPICE simulation
run. They include runtime information, warnings, and error messages and
can also be used to extract metadata about simulation performance. These
files are automatically generated by LTspice.

### `.net` Files

Machine-readable circuit description files that contain the actual
circuit topology. They define node connections, component relationships,
and directives used by the SPICE solver to compute circuit behavior.
These files are automatically generated by LTspice.

In future implementations, Python scripts can run calculations by
reading the netlist directly outside of SPICE.

### `.yaml` Files

Configuration files that store global variables and simulation
parameters. These values are referenced throughout the circuit to define
component properties, sweep settings, and equation constants.

### `.raw` Files

Binary output files generated by SPICE simulations that store waveform
data, including node voltages and branch currents over time.

### `.txt` Files

Plain-text files that typically contain exported or processed data from
SPICE simulation runs. They include summaries of raw outputs from
LTspice traces.

### `.ipynb` / `.py` Files

Python notebooks and scripts used for post-processing SPICE data. They
are used to parse `.log`, `.net`, and `.raw` files, extract metrics,
generate plots, and perform analysis of simulation results.

## Parameters

These are the parameters that must be set to run the simulation
correctly.

### LTspice Simulation Settings

> **Important:** These parameters must be set using the SPICE menu UI
> and must be reset every time SPICE is closed.

-   Relative tolerance: `2.5e-09`
-   Absolute voltage tolerance: `1e-16`
-   Absolute current tolerance: `1e-20`

To set the parameters in the SPICE window, use:

**Tools \> Compression \> Enable 1st Order Compression**

Then set the values listed above.

### YAML Configuration Parameters

The following parameters are within the `config_fit7.yaml` file and must
be referenced using the `.include {file}` directive within SPICE.

Several values must be normalized according to the conversion described
in the [Units](#units) section. Enter the **real values** into the YAML
file; conversion is handled within the schematic.

#### Real Capacitances

Multiply by `1E12` within the schematic.

``` spice
.param Cbody     = 0.50850E-18
.param Cin       = 49.8909E-18
.param Cgap      = 1.4222E-18
.param Cwirebody = 0.93964E-18
```

#### Real Inductances

Multiply by `1E18` within the schematic.

``` spice
.param Lbody = 1.696E-13
```

#### Real Resistances

Multiply by `1E3` within the schematic.

``` spice
.param Rbody = 8.40
.param Rin   = 71.90113
```

#### Electric Field Calculations

``` spice
.param epsilon1 = 6.9*55.263*1E+6
.param epsilon0 = 55.263*1E+6
.param kb       = 86.17u
.param phi      = 5.1
.param amp      = 35E-12
.param phase    = 0.72*pi
.param sigdur   = 5.1
.param q        = 1
```

All other parameters used by the simulation are found within the
schematic itself as directives.

> **Note:** Every parameter can be stored within the `.yaml` file, but
> parameters held within the schematic are easier to alter and can be
> tweaked directly.

## Procedure / Processing

### Creating a Subcircuit Symbol

1.  Define external lines in the original schematic.
2.  In the top menu, select **Net \> Name Net**, assign the desired
    name, and click on the external wires.
3.  In the top menu, select **File \> New Symbol**.
4.  In the symbol `.asy` file, select **Draw**.
5.  Draw the symbol shapes to the desired design.
6.  To add a port, select **Edit \> Add Pin/Port** and use the same name
    as the external nodes.
7.  Select **File \> Save As** and save the symbol with the same name as
    the parent `.asc` file.

### Using the `Single_Antenna_normalized` Symbol

1.  Open a new schematic.
2.  Click **Place Component**.
3.  Select **Schematic Directory**.
4.  Select `Single_Antenna_normalized`.
5.  Place the antenna components.
6.  In the top menu, select **Tools \> Save Defaults**.
7.  Check:
    -   **Save Subcircuit Node Voltages**
    -   **Save Subcircuit Device Currents**
    -   **Save Internal Device Voltages**
8.  Click **OK**.
9.  Run the simulation.
10. Select **View \> Visible Traces** and toggle the node you want to
    trace.

### Running Simulations in Python

1.  Import/install the required libraries:

    -   `PyLTSpice`
    -   `subprocess`
    -   `pathlib`

2.  In the LTspice schematic, use **View \> Update and View SPICE
    Netlist**.

3.  Copy the entire netlist.

4.  In the Python script, load the netlist into a variable:

``` python
netlist = '...'
```

5.  Define the path to the netlist:

``` python
path = "absolute/path/to/file.net"

with open(path, "w") as f:
    f.write(netlist)
```

6.  Save the LTspice executable path to a variable and use
    `subprocess.run()` to execute the simulation.

7.  Save the generated `.raw` file to a variable.

8.  Extract traces and simulation steps using PyLTSpice methods such as
    `get_trace()` and `get_steps()`.

PyLTSpice documentation:

https://pyltspice.readthedocs.io/en/latest/classes/trace.html

## Units

SPICE uses SI units by default. However, due to the
attosecond/femtosecond timescales and attofarad-scale capacitances used
in these simulations, SPICE is unable to simulate the nanoantenna
dynamics directly using SI units, likely because of numerical tolerance
limitations.

To address this, the simulations introduce the following normalized
units:

  Quantity      Normalized Unit   Conversion
  ------------- ----------------- ------------
  Capacitance   `Fn`              `10^12 F`
  Inductance    `Hn`              `10^18 H`
  Resistance    `Ωn`              `10^3 Ω`
  Time          `sn`              `fs`
  Voltage       `Vn`              `10^-12 V`
  Current       `An`              `10^-15 A`

LTspice discards changes that occur over time spans that are too short
because they are treated as numerical noise. The normalized units allow
the time domain to be stretched from femtoseconds to seconds, providing
the numerical stability required by LTspice.
